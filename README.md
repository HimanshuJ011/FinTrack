# 💸 FinTrack  (Expense Tracker Tool)

A full-stack Expense Tracker application built with:

- 🎨 Frontend: React + Vite
- ⚙️ Backend: Java Spring Boot
- 🐬 MySQL (Dockerized)
--- 

## 🚀 Features

- User Authentication (JWT-based)
- Secure login & registration
- Expense tracking with categories and real-time charts with react-recharts
- Token expiration handling

---

## 🛠️ Tech Stack

| Layer     | Technology     |
|-----------|----------------|
| Frontend  | React + Vite   |
| Backend   | Spring Boot    |
| Database  | MySQL 8 (Docker) |
| Auth      | JWT Tokens     |
| Infra     | Docker, Docker Compose |
